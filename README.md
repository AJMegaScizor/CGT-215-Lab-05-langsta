Allows a user to input text that the program converts into a cypher.
Converts capital letters to cypher by subtracting 65 in ASCII.
Subtracts 32 in ASCII for lowercase letters to convert them to their uppercase variant, then does the same subtraction of 65, and finally adds +32 to convert back to lowercase.
Ignores non-letters and just returns the same value so "!" stays as "!" and is not removed or changed from the text string.
